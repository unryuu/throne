# ADR 0010：御前消息与有限精力

状态：采纳，2026-10-15；承接 ADR 0007–0009，仅由新局启用事件生效。

每日午时统一呈列 5–10 条标题与来源，正文折起。积压按送到御前的先后排队，每日保留至少一个通政司名额；多余文书延至次日，不丢失。闭关照旧，出关恢复每日御览。消息展开、摘要原本调阅、一次吕芳谈话和一道亲发特旨各耗 1 点；同次谈话最多三轮，只在首轮扣点。每日 3 点，不累积；照票拟、留中免费，自改批红按亲发旨意计点。阅读事件仅供皇帝与观战，不进入人物经历。未读消息存入档案仍折起，可花当日精力补读。

严嵩、吕芳、陆炳可每日直送一条 brief，标题最多 20 字、正文最多 150 字，不经司礼监、不耗人物精力。吕芳每日、严嵩与陆炳每两日醒来，无收件也行动，仍用 cadence。新局常规决策护栏提高到 1000，避免每日调度过早耗尽。

陆炳每日收到 1–3 条风闻，只见内容与编号，不见真假。引用风闻可随文书标注编号，供回放追溯；不强制上报。正式锦衣卫原报仍必须选路。事实按局号、日期和固定键抽样，保留生成时的客观值、说法、真假和模糊程度。通政司混合浙江实情、少量假传闻与引擎确立的外省朝政杂事；不产生资源或行动效果。

通政司先提交当天事实清单，再单次调用模型选择标题与公文措辞。标题候选和公文前后缀由引擎提供，事实句逐字保留；解析验证候选、编号、条数，防止模型添改事实。失败显式暂停，可重试；不以模板冒充成功调用。风闻与事实元数据仅实情视角可见。以上状态、标题与阅读记录均从事件重放，旧局沿用原规则，无迁移。
