# ADR 0007：司礼监、每日理事与陆炳

状态：采纳，2026-09-23。取代 [ADR 0006](0006-court-memorials.md) 中的“御览”节奏和锦衣卫回报路径，其余规则不变。设计意图见 [DESIGN §12](../DESIGN.md#12-朝局节奏两道闸与财政2026-09-23-确认)，取舍记录见 [FEAT-0007](../issues/active/court-directorate.md)。

**每日理事。** 每日午时开一次决策点，御案可以为空。玩家处置文书、发特旨、与吕芳对话（每次至多三轮）、调阅只有摘要的原本、改常规口谕和总开关，然后退朝到次日，或闭关一至三十日。闭关期间不开决策点。

**司礼监。** 所有送给皇帝的文书先进吕芳的收件箱：外朝奏疏在严嵩票拟后，其余文书直接送达。收件箱有新文书、收到私信或口谕变更时，他在当日巳时处置一批，也就是决策点之前：呈览；口奏摘要（原文折起，可以调阅）；留中；照票拟代批（以皇帝名义发出，旨意档案注明）；发回内阁重拟（严嵩只知道是司礼监发回，并看到批语）。他另外可以给皇帝口奏几句。未处置的文书留在他手里；已留中的，以后仍可以呈上，包括在对话中呈上。他的输入包括口谕、总开关、内阁积压的清单（只有来人和题目）以及已发出的旨意。对话、调阅、陆炳单独面圣、拒绝接见，都会作为观察进入他的输入。

**陆炳与锦衣卫。** 派锦衣卫的旨意发给陆炳，不经吕芳。缇骑八日到杭，暗访五日；原报由引擎按实情写成，六日后送到陆炳手里。陆炳不能改动原报，也不能压下，只能附言，并选择交司礼监或直接面圣。回复中如有原报没选路，按格式错误处理。

**闭关与打断。** 闭关期间，吕芳（批次中）或陆炳（直接面圣时）可以请求打断，于下一个午时开一个只显示请求者和理由的决策点。玩家召见后，闭关结束，御案照常打开；拒见则闭关继续，请求者会得知皇帝不见。

**成本护栏。** 吕芳的批次和陆炳的决策计入常规决策，护栏为每局 240 次。对话由玩家发起，不计入护栏，也不改变吕芳的批次节奏。
