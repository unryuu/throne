# ADR 0009：具奏垂询与开局节奏

状态：采纳，2026-10-15。承接 [ADR 0008](0008-terminal-actors.md)，动机见 [FEAT-0010](../issues/archive/court-initiative-2026-10-15.md)。

**垂询。** 皇帝亲发 `request_memorial`，参数为在任 LLM 人物的 `actorId` 与非空 `question`（至多 600 字），不得由内阁票拟或司礼监代批。上谕经现有文书路程送达，才进入收件人的经历及 `desk/皇帝垂询.txt`，并按原时辰、间隔和成本护栏唤醒。标题与正文保留问题，观战的皇帝所见显示“垂询某某：问题”。无自动回奏、真实性保证或回复期限。

收到亲问的人开放明折和密折两条书面回奏路径（包括平日不写奏疏的吕芳、陆炳）；权限由已经送达的垂询推导，不改旧人物初始状态。明折仍经内阁票拟，密折直达司礼监，两者都由吕芳呈览。已收垂询保留在案头，提示人物结合自己的发文记录判断是否已回，不以任意一份新折冒充已经答复。被革职者仍沿用最后陈词规则。

**开局。** 仅新局在第 0 日午时安排 `court.begin`，统一唤醒六位在任人物，第 1 日辰时／巳时开始首个常规决策。其所知仍限本人前情、辖区与已送达消息，不提前透露御批。初始状态不变；旧局只恢复既有事件队列，不补发开局唤醒。

**跳过空日。** 网页“发旨并跳到下次有事”提交当前御批、特旨及口谕，同时设置 `skipEmptyAudiences`；这不是闭关，不能与多日闭关合用。每日午时照常检查，空御览提交 `court.empty_skipped` 并排下一日，世界事件与人物决定正常结算；有奏疏、口奏或插话即停止，最迟停在局终。该选项纳入事件与状态，失败重试、重启续玩保持其意图。旧存档缺少此可选字段，继续每天停下。
