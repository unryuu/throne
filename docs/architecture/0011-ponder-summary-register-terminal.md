# ADR 0011：深思、归纳、文言强度与终端御案

状态：采纳，2026-10-15；承接 ADR 0010。新规则只对新局生效，旧局按原规则重放。

## 用意

玩家多半不熟明史。稀缺的东西从“能读几条”换成“能想透几条”：读是免费的，看懂门道才费心力。阅读层次：标题（递话人自写，有偏向）→ 正文（免费）→ 括号归纳（免费，中立扫盲）→ 深思（花精力，以嘉靖的心思权衡利弊）。

## 规则

- **精力**：每日 2 点，不累积。展开消息、调阅摘要原本、补读档案改为免费。深思、召吕芳谈话（同次最多三轮，只首轮扣点）、亲发特旨、自改批红各 1 点，共用一池。数值待真人试玩后再调。
- **开局设置**（写入开局事件，随局重放，中途不可改）：
  - 文言强度三档：`classical` 现行（文书半文半白，内心与聊天古代白话）；`plain` 文书浅白文言，其余现代汉语；`modern` 全部现代汉语。只改各模型提示词里的语体要求和引擎拼接的固定文字；现代档保留官职与称谓，不用网络口语。默认 `classical`。
  - 奏疏归纳：默认开。
- **归纳**：游戏外的中立旁观者，只看正文，不知作者心思与实情，一句现代汉语点出核心意图，口语、可带点幽默，不追求细节（例：“远房宗室找你要钱”）。每日消息上御案时一次性生成，展开即见；不显示在标题列表里，以免取代递话人自写的标题。不进入任何人物的经历。
- **深思**：对某条消息花 1 点，模型以嘉靖口吻、用现代汉语写一段内心权衡：此事是谁要什么，按规矩该怎么办，背后的隐患，此人此衙门近来可疑否，可以怎么办。只能用皇帝已见过的东西（御案、档案、所发旨意、谈话）与一般明史常识，绝不读实情视角。想错无妨，嘉靖本来多疑。结果记入事件，供回放和观战，不进入人物经历。

## 终端御案

`npm run play` 默认在终端里玩，`--web` 仍开浏览器。备用屏幕、按键事件、每次按键整屏重画，不用 Ink 一类框架。操作参照 lazygit/ranger 与邮件客户端的惯例：

- 一天是一个竖列表：当日消息，之后是“召吕芳说话 ·1”“亲发特旨 ·1”“退朝”。光标所在的一条自动展开（正文、归纳、票拟、已有深思）。
- ↑↓ 移动；→ 或回车打开当前条的菜单，菜单内 ↑↓ 选、回车定、← 收起；`?` 名词小抄与按键；底部常驻按键提示。`hjkl` 作别名。
- 有票拟的文书默认“依拟”，↓ 经过只是暂记；菜单：依拟 / 深思 ·1 / 留中 / 改批…（下一层选旨意种类与对象）。无票拟的消息菜单只有深思。
- 退朝前随时可回头改。退朝回车先出当日汇总（含“几份没停下看就依拟了”），再回车才提交；在退朝行按 → 选闭关天数。闭关中被打断，←→ 二选一。
- 只有与吕芳谈话、垂询提问、特旨正文需要打字，此时临时切回行输入以便输入法工作。其余对象（县、大臣、天数）都用列表选。
- 菜单项右侧附一句白话解释。等待推进时显示无关紧要的宫中动静与调用次数，不透露人物私下所为。深思结果用打字机效果显示。
- 局终显示结局卡，回车在浏览器打开观战页看完整复盘。
- 与网页共用 `CourtService` 和存档；同一局不要两边同时开。
