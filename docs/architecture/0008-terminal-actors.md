# ADR 0008：人物经终端过一天，写信做事花精力

状态：采纳，2026-10-06。实验与数据见 [FEAT-0009](../issues/active/agent-shell.md)。

**终端。** LLM 人物的常规决策不再是一次填表，而是在一台假终端里过一天（`packages/court/src/shell.ts`）。人物可见输入摊成只读文件：`profile.txt`、`log/`（每条经历一个文件）、`province/`、`desk/`（案头待办）、`contacts.txt`、`abilities.txt` 等。查阅用常见的 bash 命令；`send` 发文书，`act` 办事，`draft` 票拟，`dispose`、`report`、`interrupt` 是司礼监的处置，`route` 转呈原报。这些命令只把意图排进当天的清单，`end --text` 写下内心并收笔。模型看到的只有一个叫 `bash` 的工具，背后不是真 shell。

**引擎不变。** 终端交出的就是原来那份决定（内心、文书、行动和各人的本职处置），照旧经 `applyDecision` 校验、结算和存档；唤醒节奏、成本护栏、失败重试和重放都不变。终端在命令当场做形式检查（收件人、文书种类、参数取值、精力），引擎仍是最终裁决。陆炳还有原报没选路时不能收笔。没收笔就在同一会话提醒一次，仍不收笔算调用失败。吕芳当面回皇上的话仍是一次回复。`THRONE_NPC_MODE=form` 可切回填表做对照。

**精力。** 写信、上奏、密奏、办一件事各花 1 点；票拟、处置本章、转呈原报、口奏不花。每日恢复 2 点，最多攒 4 点，开局满 4 点；被革职者的最后一次决策不花。超出的文书和行动由引擎以“精力不济”退回，本人下次决策时看到。精力不另存状态，由各人的决策历史推出，旧存档无需迁移。单次仍最多三份文书、三件事（引擎原先放到四份，与提示词不一致，现统一为三份）。数值待实玩调整。
