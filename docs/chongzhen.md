# 崇祯模拟器（构想，未开工）

2026-10-16 与用户讨论定下的方向，现在不做。引擎沿用嘉靖模拟器，体验要做出“什么都很急，越急越乱”。

## 已定

- **时间是稀缺物，不读秒。** 嘉靖每天有限的是精力，崇祯每天有限的是时辰：读一份、深思、召见都花游戏里的时间。一天还是玩家决定何时结束，但读得越多，一天过得越快，积压越多。
- **第一个切片：崇祯二年己巳之变。** 皇太极绕道入关，京师戒严，袁崇焕回援，城中流言说他通敌。两三个月，人物少，结局不固定。甲申（崇祯十七年最后三个月）留作之后的困难模式或结局篇。

## 机制构想

- **“急”字通胀**：人物看得到自己哪些折子被翻过、哪些被晾着，自己学会把标题写得更吓人。不写死规则。
- **消息永远过时**：沿用驿路时差。塘报到京已是几天前的事，遥控指挥、催战（孙传庭出潼关）会坑玩家。嘉靖那边时差是抢跑的工具，这边是陷阱。
- **裁驿站**：可选的省钱决策，消息更慢，还可能裁出流寇。
- **怕死循环**：可随时换人、下狱、问斩，新人从真实人名池出（温体仁、周延儒、杨嗣昌、洪承畴、卢象升、孙传庭……），前情写着前任的下场。人越怕，越报喜不报忧、推诿、等你先表态；朝令夕改时挑对自己有利的执行。急 → 问罪 → 怕 → 信息失真 → 更乱 → 更急，由人物自己的选择长出来。复盘四栏对照让玩家看到“亡国之臣”是怎么被自己逼出来的。
- **急报插队**：案头在阅读中途被八百里加急顶到最上面。和嘉靖暂缓的“北京三人的东西朝会中途送到”是同一个引擎能力，做崇祯时一起做。
- **没人替你挡**：王承恩忠心，但不筛折子。
- **钱**：沿用 DESIGN §12 的“有主的口袋”，太仓永远见底；加派三饷激起民变、多出流寇。
- **手感反转**：按键同嘉靖，但一路 ↓ 依拟会出事，又没时间每份细看。

文书量和人物更多。塘报、驿报、流寇动向多由引擎出事实、模板和库来写；只有朝廷核心五六人用大模型；被换掉的人退场，不再占调用。见长期意图：大模型与古典文字游戏互补。
