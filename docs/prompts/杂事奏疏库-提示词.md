# 给网页版 Claude 的提示词：杂事奏疏库

把下面分隔线以下的全文贴给网页版 Claude（建议开联网搜索）。导出的 markdown 放进 `packages/court/data/routine/`。

---

我在做一个明朝宫廷的文字游戏，想请你帮我写一个“杂事奏疏库”。希望你能查证史料，写得真实又好玩。

## 游戏背景

玩家扮演嘉靖皇帝，时间是嘉靖三十九年四月初一到六月中旬，大约七十五天。主线是浙江“改稻为桑”：内阁、司礼监、锦衣卫和浙江官员都由 AI 扮演，各怀心思。每天御案上有五到十条消息。其中一类是通政司汇总的“朝政杂事”：与浙江无关的各地琐事，是给朝廷添些烟火气的背景板，不推动主线。你要写的就是这类杂事，每局游戏从库里随机抽，同一局不重复。

## 要写什么

大约两百条，分十类，每类二十条左右：九边军报、钦天监天象、斋醮供用、别省雨水、驿站马匹、宗室请封、言官弹章、地方祥瑞、漕运过闸、京城米价。另有好题材，可以归入“其他”。

**取材**：优先用《明世宗实录》和嘉靖朝其他史料里的真事。嘉靖朝本来就很魔幻：献白鹿白龟灵芝的、为斋醮满天下找龙涎香的、宗室人口暴涨、禄米发不出、宗室胡闹的、言官互相弹劾的、钦天监报日食的，等等。可以把别的年份的事挪到嘉靖三十九年，但具体写到人名的，这一年必须在世、在任。没把握就别写人名，只写衙门和官职。

**不能写**：
- 浙江和浙直的任何事，东南倭寇也不写（主线在那边）；
- 这几个人：严嵩、严世蕃、吕芳、陆炳、郑泌昌、何茂才、胡宗宪、杨金水、沈一石，也不写严党与清流之争；
- 嘉靖三十九年以后才发生、或者会改变朝局的大事，比如海瑞上疏、立储。

杂事可以有请求（要钱、要封号、要赏），但别是需要皇帝当场拍板的大事。

## 好玩在哪

正文保持一本正经的公文口吻，好笑要靠事情本身的荒诞。“归纳”那一句负责说穿，比如礼部替宗室请封，归纳就写“远房宗室找你要钱”；地方报祥瑞，归纳就写“有人想拍你马屁”。

## 每条的格式（一字不差照着写，我要用程序解析）

```
### R001 · 宗室请封
- 标题：……
- 现代标题：……
- 正文：……
- 现代正文：……
- 归纳：……
- 时令：不限
- 可信度：据实
- 出处：《明世宗实录》卷××，嘉靖××年×月
- 作者注：……
```

每个字段的要求：
- **编号**：R001 起，连续编，跨批次接着往下编。
- **标题**：不超过二十字，像真实公文的事由，让人一眼想点开，或者一眼略过。
- **正文**：不超过一百二十字，用浅白的文言公文，现代人读得懂。可以补上地名、衙门、经手人、天气这类细节。
- **现代标题 / 现代正文**：同一件事的现代汉语版。保留官职和称谓，不用“谨奏”“着即”这类套话，也不用网络口语。例如“臣谨奏，伏乞圣裁”写成“臣报告，请皇上决定”。
- **数字**：所有字段一律用中文数字，不出现阿拉伯数字、百分比、小数。
- **归纳**：一句口语现代汉语，最好二十字以内，可以带点幽默。只根据正文说穿“这人到底想干嘛”，不复述经过。
- **时令**：四月、五月、六月或“不限”。大多数写“不限”；跟季节有关的才标月份，比如端午、北方麦收、别省夏汛。
- **可信度**：三选一。“据实”：真有其事，你能指出出处。“化用”：真有这类事，细节改编过。“虚构”：合乎情理，但没有本事。希望大部分是“据实”或“化用”。
- **出处**：据实的写卷次和年月，化用的写参考了什么，虚构的写“无”。查不到卷次就别编，宁可标“化用”。
- **作者注**：可选，不超过六十字，用现代汉语讲讲这件事背后的明代制度或史实，寓教于乐。玩家深思这条消息时会看到。没什么可讲的就留空。

## 怎么交付

1. 先写十条样稿，十类各一条，交给我看口味，等我反馈。
2. 之后每批三十条，每批放一个单独的 artifact，文件名“杂事奏疏库-01.md”“杂事奏疏库-02.md”……，只放条目，不加别的说明。
3. 写完一批，告诉我这批里各类各多少条、可信度各多少条。
