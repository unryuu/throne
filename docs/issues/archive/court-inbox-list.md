# FEAT-0011 补充：御案标题列表

状态：完成，2026-10-15。

当前差距：ADR 0010 的阅读权限与精力已生效，但网页仍复用旧局的整张 `DeskDocument`，正文占位和批复控件让每日标题难以扫读；现有 web 测试未覆盖御案交互。

方案：仅 `view.energy !== undefined` 使用紧凑标题行，展开状态留在前端并随 audience 重置，阅读继续提交 `open_message`。正文、原本调阅和批复编辑复用旧组件；精力置顶吸附，零精力禁开未读行并显示原因。奏疏、密奏或有票拟且尚未批复的文书标“待批复”；普通消息默认留中，不强迫处置。未读且有票拟的行保留免费依拟／留中选择，避免折叠正文迫使玩家先花精力。旧局保留卡片。中英文简介按 ADR 0010 更新。

验证：新增 4 项 React 渲染与按钮回调测试，覆盖中英文每消息一行、来源及待批复标记、未读打开回调、已读免费折叠、零精力与 pending 禁用、未读免费处置、内联编辑和旧局卡片。根目录依次通过 `npx -y pnpm@11.19.0 test`（28 文件、140 项）、`typecheck`、`format:check`、`build`；格式检查初次失败后已执行 `format` 并重验，构建仅有既有的大包提示。命令设置 `npm_config_cache=/private/tmp/codex-npm-cache` 避开默认缓存写权限限制；无新增依赖。未启动 dev server 或浏览器，视觉验收交派活窗口。
