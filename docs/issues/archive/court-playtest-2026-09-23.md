# 嘉靖朝首次实玩（FEAT-0006）

日期：2026-09-23。局号 c870c0f1-a559-4a6d-ad98-e6bc4229c8d1，记录在 gitignored runs/court/。前半段在浏览器手动玩，后半段用临时脚本代玩（依拟、汛后派锦衣卫、查实掘堤后拿问郑泌昌）。玩家由开发 agent 扮演，不是盲测。

结果：86 次调用，约 134 万 token，无失败调用。实改桑田 98 万亩（指标 50），低价兼并 22 万亩；建德大堤被人为掘开，汛至决口，死 1060 人；郑泌昌被拿问。

涌现的过程：郑泌昌第 12 日暗掘建德堤，同时修桐庐堤作样子；胡宗宪查勘建德得到河工口供，未向皇帝揭发，只私告严嵩，奏疏里写成“不逞之徒”；郑泌昌凑足亩数后想补堤，官仓无粮，工程停了；严嵩内心一再决定“只可以天灾了局，不许锦衣卫插手”；郑、杨两路重复买田，真实的 98 万亩被严嵩认定为虚报。

试玩中修掉的问题：收件人写成数组、reasoning 用满 8K 输出上限（改为 32K）、格式错误自动重问一次、未解析的回复不再缓存、完工修堤可补掘堤。修堤规则是中途改的，胡宗宪那次修堤按旧规则结算，所以本局建德决口有一部分是旧规则造成的。

遗留问题见 [HANDOFF](../../../HANDOFF.md)：决策次数上限 80 在后期用完，郑泌昌被拿问后没有触发最后决策；锦衣卫回奏把买走的淹田算成“淹田 0 万亩”，把商人粮算成“官府放赈”；密奏太多，御览过频；写给吕芳、沈一石的信没有回应。
