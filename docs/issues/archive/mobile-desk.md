# 手机御案前端

状态：完成，2026-10-16。规则与接入说明见 [手机御案](../../architecture/web-desk.md)。

## 差距与处理

原终端 `content` / `render` 按列宽和行高排版，浏览器不能直接使用。新增 `desk.html`、`src/desk/`，以原状态机驱动 DOM；仅导出结构化菜单与文书内容，终端渲染仍经过原宽度处理。旧页面、后端、模型规则和存档格式未改。

网页独立执行 HTTP、进度轮询、免费阅读后续、失败恢复、结局统计；用全屏输入面板代替行输入。测试发现输入面板挂载时控制器尚在 busy 状态，初次 focus 会落到禁用文本框；改为等待 busy 结束再聚焦。HTTP 响应丢失不代表操作失败，因此已发出的付费操作先核对存档，避免重扣精力。
