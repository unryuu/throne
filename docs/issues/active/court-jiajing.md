# FEAT-0006：嘉靖朝·改稻为桑

状态：实现中。方向见 [DESIGN §11](../../DESIGN.md#11-方向长期统治与嘉靖--崇祯模拟器)，规则见 [ADR 0006](../../architecture/0006-court-memorials.md)。

动机：赵统领二选一无法体现 LLM 的价值，也离“长期统治”太远。需要一个小朝廷骨架，让奏疏在朝廷中流转，人物自己写文书并在引擎许可范围内行动。

方案：玩家扮演嘉靖，按日推进，有文书到御案时开御览。严嵩（票拟）、郑泌昌（浙江巡抚）、胡宗宪（浙直总督）、杨金水（织造局）由真实 LLM 扮演，每次决策分别给出内心、文书、行动。改稻为桑、端午汛、毁堤、赈灾、查勘等后果由引擎计算。局终开放“所想 / 所言 / 所为 / 实情”复盘。

验证：信息隔离（输入不含他人内心和辖区外实情）、能力与实际权限校验、秘密行动证据的确定性发现、按日传递延迟、失败重试不重复已成功调用、整局无模型重放，以及浏览器实玩一局。
