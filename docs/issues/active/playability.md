# FEAT-0010：更好玩与名场面

状态：远期待开发（2026-10-06 与用户讨论后记录，未排期）。名场面清单需要用户收集。

## 一、更好玩

设想：用户对朋友说“我做了个嘉靖朝模拟器，仓库在这儿”，朋友该得到什么，才会想玩、玩得下去。

### 朋友现在打开仓库的遭遇

1. README 满是架构文档和 ADR，看不出好不好玩。（第一个流失点）
2. 想试要装 pnpm、申请 DeepSeek 密钥、起开发服务。（第二个流失点，多数人到此为止）
3. 进去是一排标签，大多是机制演示；嘉靖朝开局先批一份奏疏。
4. 推进一天要等几十秒到几分钟，看不到朝中在发生什么。
5. 第 20 天前后，御案上是一份份半文半白的公文，不知道谁在撒谎，也不知道自己做得好不好。
6. 最精彩的东西（郑泌昌掘堤、陆炳怕吕芳先看原报、吕芳“弃卒保车”）全在局终复盘里，多数人撑不到。

最好玩的部分埋在最后，前面全是门槛。

### 规划的体验

**入口**

- **观战模式（用户认为值得做）**：用已有的确定性重放，逐日翻看一局完整对局；皇帝所见与实情可随时切换，所想、所言、所为并排。做成静态页面，不需要密钥、不花钱。附一两局精选对局。
- **README 卖故事**：一句话（你是嘉靖，满朝都在骗你，你得自己看出来）、一段真实对局的所想 / 所言 / 所为对照、两个入口（“先看一局”链到观战页；“自己当皇帝”写明一条命令、所需密钥、一局大约花多少钱和时间）。架构文档放到后面。
- **低门槛试玩**：一条命令启动，或网页版填自己的密钥；成本与时长写在明处。

**局内**

- **局中就有揭穿的快感**：对质（把两人的奏报数字摆在一起责令解释）、召见套话、调阅账簿田册；查实时要有分量，人物有反应，朝局有震动。
- **目标与压力**：开局摆出国库空、修玄要钱、九边要饷、丝绸要交，每隔一段有节点逼人做选择。
- **等待不空白**：推进时滚动“朝中动静”，只放皇帝能合理得知的风声。agent 化后每人一天走几步，等待时间是要提前防的风险。
- **能晒的结局**：御批式总结卡（国库、民生、圣威、党争格局、谁欺瞒了你、揭穿了几个），附全局最精彩的一段言行反差。
- **重玩价值**：谁贪、谁忠、谁有私下安排由引擎在开局定下，每局不同；以后加崇祯朝，节奏完全不同。

### 下一步能做什么

在 agent 化之外插一个“能给朋友看”的小里程碑：观战模式和一局精选对局；README 改成卖故事；局中揭穿的反馈和结局卡。前两件几乎不碰引擎，可以和引擎工作并行。

另需掂量命名：“大明王朝1566”是电视剧名，公开仓库可叫“嘉靖朝模拟器”，注明灵感来自该剧。

## 二、名场面

### 思路

不写死剧情（DESIGN 的涌现原则），而是把名场面发生的条件摆齐，让它很可能出现。一场名场面可拆为四样：人物的脾性、压力处境、当面的舞台、能演出来的表达。现在缺的主要是后两样：所有交流都是文书，没有“当面”，模型也惯写公文腔。

要补的机制：

- **当面场景与舞台动作**：召见、廷议、内阁会议时，人物除了说话还能给出动作（跪下、免冠、举奏疏、沉默），观战时排成剧本样式。
- **“当面说”与“写公文”分开**：当面说要短、要冲，明确允许动气、失态。
- **玩家自己演嘉靖的戏**：给玩家当面发作的舞台，在场的人都听到并各自反应；好笑的是他们的反应。
- **人物档案写说话的气口**：严嵩老成、绵里藏针，吕芳软中带硬，海瑞刚直。只描述风格，不照抄台词。
- **局后说书人**：一局结束后调一次模型，挑出最有戏的几段并起标题，作为观战目录。

### 已拆的两场

- **严世蕃“两京一十三省在我肩上担着，天下苍生还轮不到你来说”**：NPC 的戏。需要严世蕃与清流成为对立的 LLM 人物，当面会议你来我往、能顶嘴打断，当面说的通道短而有力。基本就是切片 D（年终内阁会议开局）的验收样本。
- **嘉靖“朕的钱！他们拿两百万，朕拿一百万，朕还要感谢他们吗”**：玩家的戏，游戏要让玩家真的气到想说。需要钱分装在各口袋、经手人截留（切片 C）；有人上奏邀功；查账查出实数；召见时能当面发作，且有后果。前提是玩家在乎那笔钱，所以修玄花内帑这类私人目标要有真实分量。

结论：名场面正好落在切片 C（财政）和 D（开局会议）上，它们不只是加深度，也是戏的来源。

### 风险

用真名时，模型可能直接背出剧中原句。场合对是致敬，场合不对很尴尬，而且那是背诵不是涌现。可用 DESIGN 里规划的化名对照检验：换了名字，这类戏还出不出得来。

### 待用户收集

名场面清单，十来场即可。凭记忆讲场景就行，记下谁在场、因为什么、哪一下最好看，台词记不全也没关系。收集后逐场按四要素拆，对照缺失的机制，作为 C、D 的体验验收标准：实玩中出现同类的戏，才算做成。
