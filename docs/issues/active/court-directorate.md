# FEAT-0007：司礼监、每日决策点与陆炳

状态：实现中，HANDOFF 切片 B。设计意图见 [DESIGN §12](../../DESIGN.md#12-朝局节奏两道闸与财政2026-09-23-确认)。

动机：首局与[第二局](../archive/court-slice-a.md)御览几乎隔日一次；严嵩 61 本外朝奏疏 57 本一日内票拟，压奏疏没有风险也没有好处，两道闸形同虚设；锦衣卫是皇帝万能的真相通道。

## 已定（2026-09-23 用户确认）

- 吕芳成为 LLM 人物，按 HANDOFF B 处置文书；皇帝的常规口谕和总开关每次进入他的输入。每日午时一个决策点，闭关期间跳过。
- 严嵩压着不票拟：吕芳看得到内阁积压清单（哪些本章到了内阁尚未票拟），催不催、报不报由他决定。不设超时自动呈上。
- 吕芳发回重拟：严嵩只知道“司礼监发回”和吕芳的批语，不知是否圣意。不设次数上限，每次发回记入双方经历。
- 中旨：沿用现有特旨，不抄送内阁；严嵩只能从后果或来信得知。
- 锦衣卫：派遣不经吕芳，吕芳只能从风声得知。查案要花时间；陆炳成为 LLM 人物，缇骑的原报先到他手里，由他决定交司礼监（进吕芳的批次）还是直接面圣。

- 陆炳（2026-09-23 确认，架空历史：史上此时已故）：缇骑南下 8 日、暗访 5 日，原报送回北京交陆炳，约 20 日才到御前。原报由引擎按实情生成，陆炳不能改、不能压，只能附言并在两条路中选一条。交司礼监是常规程序；直接面圣则吕芳经手不了，但会知道陆炳单独见了皇上。皇上闭关时，他可以等出关，也可以请求打断，见不见由玩家决定。

## 方案

- **每日决策点**：每日午时一次，有无本章都开。玩家可以处置御案文书、发特旨、与吕芳对话（每次至多三轮）、调阅吕芳只口奏了摘要的原本、改常规口谕和总开关，然后退朝进入下一日，或闭关 N 日。取代原先文书一到就开御览、十日空转一次的节奏。
- **吕芳的批次**：他的收件箱有新文书、收到私信或口谕变更时，于当日巳时（决策点之前）调用一次。输入含口谕与总开关、收件箱、他留中的旧本、内阁积压清单（仅来人与题目）。输出口奏和逐本处置：呈览、口奏摘要（原文折起，可调阅）、留中、照票拟代批（以皇帝名义发出，旨意档案注明司礼监代批）、发回重拟。未处置的仍留在收件箱。闭关期间他可以请求打断。
- **吕芳知道的圣意**：与他的对话、调阅原本、陆炳单独面圣、拒见打断，都作为他的观察。
- **成本**：吕芳和陆炳计入成本护栏，护栏提到 240；对话由玩家发起，不计入，但每个决策点至多三轮。

验证：两道闸与陆炳两条路各自的信息边界（严嵩看不到留中与口奏，吕芳看不到直奏内容）、闭关与打断、对话和调阅进入吕芳的观察、整局确定性重放，以及实玩一局。
