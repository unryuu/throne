# FEAT-0008：NPC 提示词缓存

状态：实现完成，待实测。

动机：第三局 259 次调用，缓存命中率只有 3%–18%。输入开头是每次都变的决策编号和时间；收到的文书、见闻和历史各取最近若干条的滑动窗口，还带会翻转的“是否新到”标记，前缀几乎每次都变。

方案：见 [ADR 0006](../../architecture/0006-court-memorials.md) 信息边界一节。吕芳收到的本章改记为他自己的一条见闻，待办处置只引用它。

验证：用第三局的记录离线重放，比较同一人物相邻两次提示词的公共前缀。旧排法为 4%–7%，新排法为 84%–95%；提示词长度约翻一倍，未命中缓存的部分约减少八成。缓存只省输入，思考和输出不受影响。下一局实玩时核对 DeepSeek 返回的实际命中数。
