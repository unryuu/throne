# FEAT-0012：归纳、深思与开局语体

状态：完成。规则与终端御案均已实现，见 [ADR 0011](../../architecture/0011-ponder-summary-register-terminal.md)。

原有差距：ADR 0010 在开局事件启用三点精力和阅读收费，没有语体设置或皇帝辅助理解调用。新局在 `information.enabled.settings` 保存 `{ register, summaries }`，默认 classical + 开归纳；无该字段的旧局继续三点/阅读收费，更早无 information 的局也保持原状。

实现：归纳只接收正文数组，司礼监折起的原文以吕芳呈报摘要替代；每日呈阅批量生成，谈话中新呈文书另补一批。先保存呈阅批次，再单独调模型，失败重启只重试归纳。深思只投影 `courtRulerView` 的当前消息、御案、档案、旨意、谈话和口奏，结果存事件，不进人物经历。语体贯穿表单、终端日、通政司及固定开场文书、批红、锦衣卫原报；归纳和深思始终现代汉语。

终端接入：直接 `CourtService.create(locale, { register: "modern", summaries: true })`；展开用 `act(id, audienceId, { type: "open_message", documentId })`，深思同样传 `{ type: "ponder", documentId }`，先展开再深思。视图提供 `settings`、`energyCapacity`、`gloss` 和 `ponders[{at,text}]`；存档与 HTTP 共用原有服务，不需要终端专用持久化。

网页已加设置、免费展开/档案补读、括号归纳、深思按钮与历史、名词小抄及悬停说明。观战转换及页面能显示归纳和深思。代玩：`court-autoplay.ts 3 --register=modern --summaries=true`，默认也是 modern + 开归纳，偶数日深思。

验证：30 个测试文件、155 项测试通过，format:check、typecheck、build 通过（保留已有的大包提示）。新增测试检查实情隔离、免费阅读、共享精力、归纳开关/批量、失败恢复、语体传递及确定性重放；网页组件测试验证零精力展开和正文内显示。没有可用浏览器，未做截图验收。旧局 `d9f36214-9eba-4b1f-b7a4-de04111fb185` 与 `c9d32fb1-5afa-41c6-ae70-22f54900dcbe` 均以 `CourtService.get` 成功读取，后者仍显示容量 3、剩余 0，未调用模型。

## 终端御案（完成，2026-10-15）

`apps/web/tui/main.ts` 直接驱动 CourtService；`state.ts` 提供纯按键状态转换、动作请求与文本渲染，`terminal.ts` 管备用屏幕、raw mode、行输入与恢复。`local.ts` 列出未完局并启动本机观战服务。没有修改引擎、网页规则或存档格式，也未增加依赖；中文按显示宽度折行，组合字符和 emoji 按字素处理。

## 终端手感修订（完成）

主流程验收后的七项反馈已处理。原因为折行器丢失续行缩进、菜单渲染未带入文书、桌面杂项直接铺开、提示栏没有按场景区分，以及 cooked 行输入既无法编辑又复用了主屏位置。

`state.ts` 现保留正文/归纳/票拟/深思的段落缩进，吕芳回话续行对齐正文；标点与前字一起排版，避免中文句读落到行首且不溢出终端宽度。菜单及改批各层上方固定当前文书，长正文以 PgUp/PgDn 翻阅。桌面以“更多…”收起档案、旨意/口奏/谈话和常例，退朝始终最后；页脚按场景提示。开局默认选中登基，选完语体自动回登基。小抄改为 localization 的共享词条，终端逐行对齐，网页使用 `dl`。

输入留在备用屏幕，清屏后保留谈话或文书，上下文下面独立显示输入区。readline terminal 模式负责中文编辑，空行/Esc 均取消；无需正文的旨意有明确的“按所选办法拟旨”选项。实测发现本工具环境 `TERM=dumb` 会让 Node 的 readline 自动降级，故只在行编辑期间对该值临时使用 ANSI 模式，离开输入恢复；未修改用户的终端配置。

验证：补充默认开局、更多层级、菜单文书上下文、长文翻页、悬挂缩进/中文避头、小抄逐行与三种返回键、输入上下文/取消，以及网页双语 `dl` 回归测试。macOS pyte 的 80×26 屏幕实测，含默认开局、菜单→改批→选县→派谁查、更多、小抄、中文插入/左右键/退格、空行和 Esc 取消、谈话后退朝到次日；另测输入中缩窗和 Ctrl+C，终端属性恢复正常。启动入口、SIGTERM 与异常恢复复测通过。脚本、ANSI 和完整屏幕保留在本机 `runs/tui/polish/`，缩窗记录在 `runs/tui/polish-input-resize/`。未新增真实模型调用。

四项检查全过：format:check、typecheck、test（31 文件 / 174 项）、build；仍仅有既有的大包提示。本轮网络受限，用 `npm_config_offline=true npm_config_cache=/tmp/throne-npm-cache npx -y pnpm@11.19.0` 从已有缓存执行各命令。
