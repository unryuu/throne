# Status

Direction changed on 2026-09-23: the project now studies a long reign ("Jiajing / Chongzhen simulator"), fun-first with real names. See [DESIGN §11](docs/DESIGN.md#11-方向长期统治与嘉靖--崇祯模拟器).

The default web tab is now the Jiajing court (FEAT-0006, in progress): the player is the emperor. Yan Song drafts rescripts. Zheng Bichang, Hu Zongxian and Yang Jinshui are live DeepSeek actors who each think, write and act separately. Paddy-to-mulberry, the Duanwu flood, dike sabotage, relief, riots and inquiries are resolved by the engine. Runs save after every step under gitignored `runs/court/` and resume after a server restart. The reign-end review shows thought / word / deed / truth side by side. Rules: [ADR 0006](docs/architecture/0006-court-memorials.md).

First live playtest finished: Zheng Bichang secretly breached the Jiande dike, Hu Zongxian found out and told only Yan Song, and the Embroidered Guard exposed it and Zheng was arrested. Record: [playtest](docs/issues/archive/court-playtest-2026-09-23.md).

The seven mechanism demos and the two-decree live commander remain available as earlier tabs.

Slice A done (2026-09-23): regular decisions have a 160-call cost guard that is shown when hit, an arrested minister always gets his last decision, and Embroidered Guard reports give the inundated area and separate merchant grain from official relief. Second playtest: 128 calls, about 2.24M tokens. Record: [BUG-0007](docs/issues/archive/court-slice-a.md).

Slice B done (2026-09-23): Lü Fang and Lu Bing are live. Every paper reaches the throne through Lü Fang, who presents, summarises, holds, endorses on the draft or returns it to the cabinet. Embroidered Guard reports go to Lu Bing, who either hands them to the Directorate or brings them in person. The emperor holds court daily at noon, can talk to Lü, and can go into seclusion. Rules: [ADR 0007](docs/architecture/0007-directorate-daily-court.md). Third playtest: 259 calls, about 4.65M tokens; the 240-decision cost guard ran out on day 73. Record: [FEAT-0007](docs/issues/archive/court-directorate.md).

Checks: tests, types, formatting and build pass (the chunk-size advisory is non-blocking).

Prompt caching (2026-10-06): about 91% of input hits the cache in terminal mode ([FEAT-0008](docs/issues/archive/prompt-cache.md)).

Embroidered Guard rule (2026-10-06): only the emperor can dispatch the Guard, so Yan Song's drafts and Lü Fang's proxies cannot; letters to people nobody plays (the Guard, Shen Yishi) or to the emperor are returned to the sender. See [ADR 0007](docs/architecture/0007-directorate-daily-court.md).

Terminal actors (2026-10-06): every LLM actor's regular decision is now a day in a fake bash, with duty commands for Yan Song, Lü Fang and Lu Bing; the engine still settles the same decision. Writing and doing cost energy (1 a day, up to 3). Two 15-day playtests: at 2 a day energy never bound; at 1 a day decisions fell from 24 to 14 and model cost roughly halved, with no failures. Rules: [ADR 0008](docs/architecture/0008-terminal-actors.md); notes: [FEAT-0009](docs/issues/active/agent-shell.md).

Spectator milestone (2026-10-06): a static spectator page (`apps/spectator`) steps through saved runs day by day, switching between what the emperor saw and what happened, with an ending card. It ships the first playtest (the Jiande breach) and the 15-day terminal run, with hand-picked scenes whose quotes a test checks against the actors' own words. The README now leads with the story. A GitHub Pages workflow publishes the page from `main`. See [FEAT-0010](docs/issues/active/playability.md).

Local spectating and storyteller (2026-10-15): the spectator dev server lists local saves; a finished run gets one DeepSeek "storyteller" call that picks scenes and writes the ending card, aiming for fun over verbatim accuracy (unmatched quotes show as retellings). Side-by-side with hand-picked versions: `runs/storyteller/对照.md` (local only). The spectator page is live on GitHub Pages and now also carries the full terminal-mode reign ("一本真账", on the branch, not yet on `main`).

Imperial questions and opening (2026-10-15): the emperor can ask any live minister a question that travels like other papers and opens memorial/secret-memorial replies; all ministers act from day 0; the web desk can skip to the next day with something on it. Rules: [ADR 0009](docs/architecture/0009-imperial-questions.md). A 10-day playtest showed the ask-and-answer loop works but takes about two weeks for Hu Zongxian (Taizhou is 7 days away).

Imperial inbox (2026-10-15): each day the emperor gets 5–10 titled messages (notes straight from Yan Song, Lü Fang and Lu Bing; 通政司 reports built from engine facts, some leaked truth, some routine, a few false; plus memorials). Titles are free; opening one, talking to Lü Fang or a personal edict costs 1 of 3 daily energy; following a draft unread is free. Lu Bing gets 1–3 rumours a day without knowing which are true. Rules: [ADR 0010](docs/architecture/0010-imperial-inbox.md); 20-day playtest: [FEAT-0011](docs/issues/archive/court-inbox-2026-10-15.md). The 通政司 clerk now writes freely around each fact (no raw engine numbers). Open: the desk shows each message as a full card rather than a compact title list.

Sharing (2026-10-15): friends clone the repo and run `npm run play`, which installs dependencies, asks once for a DeepSeek key (hidden input, saved to `secret/`), starts the game and opens the browser; the web court has a "新开一局" button. README estimates a full game at about 23M tokens, roughly $1.6–3.2 at 2026-10-15 prices. Land-for-grain now fails where there are no flood victims and no flooded land; the storyteller keeps every actor's full thoughts in its input.

Ponder, summaries, register, terminal desk (2026-10-15): reading is now free and the emperor has 2 energy a day; pondering a message (a DeepSeek monologue in Jiajing's voice, built only from what the emperor has seen), talking to Lü Fang, a personal edict or a rewritten rescript each cost 1. A neutral outside reader adds a one-line plain-Chinese gloss to each message. New games choose classical / plain / modern register. `npm run play` now opens a full-screen terminal desk driven by arrow keys and Enter (`--web` for the browser, `--demo` without a key). Old saves keep their old rules. Rules: [ADR 0011](docs/architecture/0011-ponder-summary-register-terminal.md); notes: [FEAT-0012](docs/issues/active/ponder-summary-register.md). Not yet played by a human.

Speed and usage (2026-10-15): before tuning wait time, tokens or cache hits, read [docs/performance.md](docs/performance.md); `reasoning_effort: low` does nothing on deepseek-flash, and fewer terminal round trips did not shorten a day.

Web game plan (2026-10-15, draft): put the game online with the user paying for model calls (daily spending cap, no invite codes); default register plain. First step is opening packs (a call-fingerprint cache pre-run over the 9 day-0 branches to day 5, so the first days need no waiting) plus a hand-written routine-memorial library; then a web front end built on the terminal state machine with touch gestures; then deployment to `1566.unryuu.top` on vps-02 (Hong Kong; page and back end on one domain). Rules: [ADR 0012](docs/architecture/0012-opening-packs-and-memorial-library.md). Fingerprint cache, stable document ids, seeds, pack builder (`pnpm opening-packs`, `--plan` previews cost; all 10 groups estimated at US$16–32), presets, ponder author notes and busy hints are in; a real smoke run hit 13/13 with near-zero waits. Full packs are built only after the memorial library is wired in, since it changes fingerprints. Notes: [opening-packs](docs/issues/active/opening-packs.md).

Web game build-out (2026-10-16): the routine-memorial library is wired in (multi-model sources under `packages/court/data/routine/`, keys `source/Rnnn`, 403 of 415 entries load; self-check `npx tsx apps/web/server/routine-library.ts`). A phone-first desk (`/desk.html`, `apps/web/src/desk/`) drives the terminal state machine with taps and a bottom thumb bar (no swipes yet). A standalone server (`npm run serve`, `apps/web/server/standalone.ts`) serves it behind channel passcodes (`secret/passcodes.json`: 作者自用 / 朋友圈 / 小红书, the last disabled until a site-wide spending cap exists), with per-channel daily run caps and analytics (`npx tsx apps/web/server/analytics-report.ts`). Deployment notes: [docs/deployment.md](docs/deployment.md). Deployed to https://1566.unryuu.top on vps-02 (2026-10-16; nginx SNI split shares 443 with the xray proxy). One plain-register opening pack is live (new games open in under a second); more groups only if more people play. Waits show palace atmosphere and a timer, never who is busy (that leaked who was acting).
